三层人才技能培训与考试管理系统 · 使用说明（免安装版）
============================================================

这个包是什么
------------------------------------------------------------
一套能直接跑起来的「变电运维人才技能培训与考试管理系统」。
不需要装 Docker、不需要装 Java、不需要装 Node、不需要装 MySQL，
也不需要联网 —— Java 运行环境和 MySQL 都已经打包在这个文件夹里了。

你只要：把整个文件夹解压到任意位置（路径里有空格也没关系），双击 start.bat。

一、第一次启动
------------------------------------------------------------
双击 start.bat，然后等。脚本会自己做完这些事：

  1. 检查运行环境（用包内自带的 Java 和 MySQL，不碰你电脑上已有的任何软件）
  2. 生成配置（随机数据库口令、随机令牌密钥、自动挑没被占用的端口）
  3. 初始化数据库（建库建表，约 10-30 秒）
  4. 启动 MySQL 与后端服务
  5. 等网页能打开，然后自动打开浏览器

第一次大概要 1-2 分钟，之后每次只要十几秒。
窗口里会打印进度，看到「服务已就绪」就可以用了。

二、打开网页
------------------------------------------------------------
启动完成后屏幕上会打印两行地址：

  本机：                 http://localhost:8080
  同一局域网的其他电脑： http://192.168.x.x:8080

自己用第一行；把第二行（连同 http:// 和端口一起）发给同事，
他们在同一个局域网用浏览器就能打开。

端口以屏幕打印的为准：8080 被别的软件占用时，脚本会自动换成别的空闲端口。

四、想让诊断结论由大模型生成（只差一个 key）
------------------------------------------------------------
本包已经预置好配置文件 .env：大模型开关（AI_ENABLED）是打开的，里面只缺一个 key。

  1. 用记事本打开本目录下的 .env
  2. 找到这一行：            AI_API_KEY=
     在等号后面粘上你的 API key（不要加引号、等号后面不要留空格），保存
  3. 重新双击 start.bat

启动窗口里会打印一行大模型体检结果：

  大模型连通：xxx 有响应    → 正常。此后「个人诊断」与「公司运行诊断」的结论都由大模型实时生成
                              （界面上会标注「大模型 xxx · 实时计算」；走内置规则时标注「规则引擎 v1」）
  大模型连不通：<原因>      → 诊断会自动回退成内置规则结论，照常可用；按提示的原因修好再重启即可
  大模型已开启，但还没填 key → 按上面三步把 key 填进去

不填也能用：没填 key 时诊断自动走系统内置规则引擎，照常出结论，只是措辞是固定模板。

默认已按 DeepSeek 配好（AI_BASE_URL / AI_MODEL 不用改）；换服务商改这两行即可，见 .env 里的注释。
只想离线演示、完全不接大模型：把 AI_ENABLED 改成 false。

注意：填了 key 之后，系统会把员工/企业数据发给这个模型服务商来生成结论。
      涉及真实人事数据时，请先确认符合本单位的数据合规要求。

六、常见问题
------------------------------------------------------------
Q: 别人打不开我给的地址？
   1. 确认两台电脑在同一个局域网（同一 Wi-Fi / 同一路由器），没开「客户端隔离」。
   2. 确认发的是「同一局域网的其他电脑」那一行地址，不是 localhost。
   3. Windows 防火墙挡住了。用「以管理员身份运行」的 PowerShell 执行一次
      （把 8080 换成你实际的端口）：
        netsh advfirewall firewall add rule name="PowerTrain Web 8080" dir=in action=allow protocol=TCP localport=8080
   4. 公司或酒店的 Wi-Fi 常做终端隔离，换手机热点或换个路由器试试。

Q: 双击 start.bat 一闪就没了 / 报错？
   在包根目录按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，然后执行：
     powershell -ExecutionPolicy Bypass -File tools\start.ps1
   报错信息会留在窗口里，可以复制出来发给维护者。

Q: 提示端口被占用？
   不用管，脚本会自动换成空闲端口，并写回 .env。以屏幕打印的地址为准。

Q: 诊断出来了，但结论不是大模型写的？
   看启动窗口里那行大模型体检提示：
     「大模型已开启，但还没填 key」→ 按第四节把 key 填进 .env（改完必须重新双击 start.bat 才生效）
     「大模型连不通：…」           → 照冒号后面的原因处理，常见三种：这台电脑上不了外网 / 需要走网络
                                    代理 / key 或 AI_BASE_URL 写错了。修好之前诊断自动回退规则结论，不影响使用。

Q: 电脑重启后还要再双击一次吗？
   要。这套是免安装的绿色版，不写注册表、不装系统服务，不会开机自启。
   重启后双击 start.bat 即可，数据都在 data\ 目录里，启动只要十几秒。

Q: 想搬到别的电脑？
   整个文件夹拷过去就行。注意数据在 data\ 里、口令在 .env 里，是一套的。
   想在新电脑上从零开始，就先删掉 .env 和 data\，再双击 start.bat。

Q: 想彻底卸载？
   先双击 stop.bat 停掉，然后直接删掉整个文件夹。不写注册表、不留系统服务。

七、关于安全（重要）
------------------------------------------------------------
- 当前版本登录不校验密码，只认账号名。任何能访问到这个地址的人都能以管理员身份进入。
  所以只在你信任的局域网里用，不要直接映射到公网。要做对外发布，先接内网统一身份。
- 数据库只监听 127.0.0.1，同网段的电脑连不到数据库，这是有意为之。
- .env 里存着数据库口令、令牌签名密钥和大模型 API key（大模型那一项默认是空的，要你自己填）。
  要把这个文件夹转发给别人之前，先把你填的 AI_API_KEY 清空（其余留着不动即可），
  或者把 .env 和 data\ 一起删掉，让对方第一次启动时重新生成一份。打包脚本也会校验：
  包里的 AI_API_KEY 必须是空的，否则拒绝出包。
