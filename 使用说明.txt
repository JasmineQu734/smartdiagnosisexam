三层人才技能培训与考试管理系统 · 使用说明
============================================================

这个包是什么
------------------------------------------------------------
一套能跑的「变电运维人才技能培训与考试管理系统」。你不需要装 Java、Node、MySQL，
只要装好 Docker Desktop，双击一个文件就能在本机跑起来，并让同一个局域网（同一个
Wi-Fi / 网线）里的其他电脑用浏览器访问。

一、开始之前（只做一次）
------------------------------------------------------------
1. 装 Docker Desktop：https://www.docker.com/products/docker-desktop/
   Windows 版安装时保持默认勾选「Use WSL 2 instead of Hyper-V」，装完重启一次电脑。
2. 第一次打开 Docker Desktop，等左下角变成绿色的「Engine running」再继续。
3. 确认系统盘（C 盘）至少留 15 GB 空闲空间。

二、启动
------------------------------------------------------------
双击根目录的「启动.bat」。脚本会自己做完下面这些事，你看着就行：

  1. 检查 Docker 装没装、跑没跑（没跑会自动帮你打开 Docker Desktop）
  2. 没有配置文件就自动生成一份（端口、随机数据库密码、随机令牌密钥）
  3. 检查端口有没有被别的软件占用，占了自动换一个
  4. 拉起服务
  5. 等网页能打开
  6. 在屏幕上打印访问地址

首次启动要 5-15 分钟（要构建镜像），窗口会停在等待状态，别关，等它打印「启动完成」。
之后每次启动只要十几秒。

三、打开网页
------------------------------------------------------------
启动完成后屏幕上会打印地址，大致是这样：

  本机：                 http://localhost:5173
  同一局域网的其他电脑： http://192.168.x.x:5173     ← 这个给别人用

把第二行地址（连同 http:// 和端口一起）发给同事，他们在同一局域网用浏览器打开就行。
如果对方打不开，见第七节。

（端口以屏幕打印的为准：5173 被占用时脚本会自动换成 5174 或别的空闲端口。）

五、想让诊断结论由大模型生成（可选）
------------------------------------------------------------
不配也能用：诊断会走系统内置规则引擎，照常出结论，只是措辞是固定模板。
想让它像 AI 一样给出「深度思考」的分析，按三步做：

  1. 用记事本打开本目录下的 .env，在 AI_API_KEY= 后面填上 API key
  2. 把 AI_ENABLED=false 改成 AI_ENABLED=true
  3. 用「以管理员身份运行」的 PowerShell 执行：
       docker compose up -d --force-recreate backend

默认已按 DeepSeek 配好（AI_BASE_URL / AI_MODEL 不用改）；换别的服务商改这两行即可，
见 .env 里的注释。

注意：填了 key 之后，系统会把员工/企业数据发给这个模型服务商来生成结论。
      涉及真实人事数据时，请先确认符合本单位的数据合规要求。

六、常用操作
------------------------------------------------------------
  停止服务      双击「停止.bat」（数据保留，下次启动照旧）
  只体检不启动  启动.bat -Check
  改了代码重建  启动.bat -Rebuild
  看运行日志    docker compose logs -f --tail 100
  彻底清空重来  docker compose down -v      ← 会删掉全部数据，慎用

七、常见问题
------------------------------------------------------------
Q: 别人打不开我给的地址？
   1. 确认两台电脑在同一个局域网（同一 Wi-Fi / 同一路由器），没开「客户端隔离」。
   2. 确认发的是「同一局域网的其他电脑」那一行地址，不是 localhost。
   3. Windows 防火墙挡住了。用「以管理员身份运行」的 PowerShell 执行一次
      （把 5173 换成你实际的 Web 端口）：
        netsh advfirewall firewall add rule name="PowerTrain Web 5173" dir=in action=allow protocol=TCP localport=5173
   4. 公司或酒店的 Wi-Fi 常做终端隔离，换手机热点或换个路由器试试。

Q: 双击「启动.bat」一闪就没了 / 报错？
   在根目录按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，然后执行：
     powershell -ExecutionPolicy Bypass -File tools\launcher\start.ps1
   报错信息会留在窗口里，可以复制出来发给维护者。

Q: 提示端口被占用？
   不用管，脚本会自动换成空闲端口，并同步写回 .env。以屏幕打印的地址为准。

Q: 想换端口 / 换数据库密码？
   编辑根目录下的 .env（里面有中文注释），改完重新双击「启动.bat」。
   注意：数据库密码只在数据卷第一次初始化时生效，事后改 .env 改不掉老库的密码；
   真要换得先 docker compose down -v 清库（数据会没）。

Q: 电脑重启后还要再双击一次吗？
   不用。三个服务都带 restart: unless-stopped，Docker Desktop 一起来就会自动拉起。
   只有你手动双击过「停止.bat」才需要再手动启动。

八、关于安全（重要）
------------------------------------------------------------
- 当前版本登录不校验密码，只认账号名。任何能访问到这个地址的人都能以管理员身份进入。
  所以只在你信任的局域网里用，不要直接映射到公网。要做对外发布，先接内网统一身份。
- 数据库容器默认只绑定本机回环地址，局域网里的其他电脑连不到数据库，这是有意为之。
- .env 里存着数据库密码、令牌签名密钥和（如果填了）大模型 API key。
  要转发这个文件夹给别人之前，先删掉 .env，让对方首次启动自动生成一份新的。
